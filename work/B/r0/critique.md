# Дыры, найденные при роли соперника (и что заменено)

- reg-06 ЗА: «память хранит эмоцию» без опоры -> заменено механизмом внимания (съёмка отнимает момент) и ударом «лайк против привычек». ПРОТИВ: 56% — маркетинговый опрос -> тезис сведён к выбору места, вес ценности не утверждается.
- reg-07 ЗА: «все отряды профильные» неверно -> добавлено признание сервисных отрядов, критерий смещён на договор и профильные направления. ПРОТИВ: «большая часть не по специальности» без цифр -> «часто», цифр не называем.
- reg-08 ЗА: «дешевле» без данных -> заменено на гибкость и отсутствие посредника. ПРОТИВ: «лишний риск» без статистики -> сделан упор на цену ошибки и нагрузку на спасателей; обязательность уведомления МЧС не утверждается.
- reg-09 ЗА: «врач разъясняет, донор вправе передумать» — не проверено -> убрано. ПРОТИВ: доверие низкое без опросов -> прямо признано, довод строится на разрыве потребность/база (2022) и 260 тыс./12–15 тыс. в год.
- reg-10 ЗА: «рынок требует ИИ» без данных -> заменено механизмом (навык строится годами) и ограниченностью шагов. ПРОТИВ: «гонка» не бьёт по малым шагам -> переведено на стандарт 2027 и нехватку учителей.
