**Определение.** Судим по трём группам показателей: (1) сколько времени уходит на дорогу (в день, до работы; индексы пробок); (2) как люди ездят (доля общественного транспорта, автомобилизация, метро/трамвай); (3) что рядом с домом («15 минут пешком» до магазинов, поликлиник, школ; ожидание приёма врача).

**Важно о методе.** Поисковый лимит сессии (200 WebSearch на ход, общий для всех агентов) исчерпан после ~17 запросов, не 12–15+ на тему по плану: часть планируемых запросов (2ГИС по Екатеринбургу/Новосибирску/Казани, плотность метро по городам, СберИндекс, ИКГС по транспорту) не выполнена. Попытка `audit/fetch.py` на странице Яндекса (yandex.ru/company/news/23-12-2025-02) дала `403 CONNECT tunnel failed`; WebFetch на kommersant.ru дал `ENOTFOUND`. Поэтому у ВСЕХ записей статус «по выдаче» (цифра видна в тексте результата поиска, страница не открыта). Запрещённые источники (The Moscow Times и др.) не использованы, хотя попадали в выдачу.
