# Debattle — подготовка к турниру «Твой Ход × Дебаттл»

Цель: карточки подготовки по 50 темам (30 окружных + 20 региональных), сайт-тренажёр
для телефона (GitHub Pages, папка docs/) и офлайн-версия одним файлом (docs/offline.html).
Команда из 3 человек, турнир скоро — скорость и надёжность важнее полировки.

## Правила экономии (тариф Pro, лимиты малые)
- Не перечитывай файлы без нужды. Исходные PDF уже вытащены в work/*.txt.
- Субагентам давай только нужный кусок данных (тему, схему карточки), не весь репозиторий.
- Результат каждого шага сразу пиши в файл. Длинные тексты в чат не выводи.
- Промежуточное — в work/<буква сессии>/<группа>/, чтобы продолжить после обрыва.

## Структура
- spec/SPEC.md — спецификация (кластеры, стиль, схема карточки, цикл спора, сайт)
- docs/index.html — сайт; docs/offline.html — собирается build.py (не править руками)
- docs/data/topics.json — 50 тем; banks.json — универсальные банки; cards/<id>.json — карточки
- work/ — рабочие файлы; build.py — сборка офлайн-версии; session-handoff.md — сводка

## Правила
- Тема готова, если есть файл docs/data/cards/<id>.json.
- Подробности — в spec/SPEC.md, читай только нужный раздел.
- Стиль: строка до 15 слов, без канцелярита, ни одной выдуманной цифры/цитаты (verified: false).
- После изменений данных: python3 build.py; push — только по подтверждению.
